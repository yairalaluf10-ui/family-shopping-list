# רשימת הקניות של המשפחה 🛒

אפליקציית ווב משותפת לרשימת קניות משפחתית. כל בן משפחה מוסיף מה שחסר מהטלפון, והרשימה מתעדכנת אצל כולם בזמן אמת.

**כתובת חיה:** https://alaluf-family-list.netlify.app

A shared, real-time family shopping list (Hebrew, RTL). Vanilla JS PWA on Firebase (Firestore + anonymous auth), hosted on Netlify.

## מה היא עושה

- **בלי חשבון ובלי סיסמה.** נכנסים דרך קישור הזמנה עם קוד סודי, וכותבים שם פעם אחת.
- **סיווג אוטומטי למחלקות בסופר** לפי שם המוצר: 11 מחלקות, עם אייקון לכל מחלקה.
- **סנכרון בזמן אמת** בין כל הטלפונים, דרך Firestore.
- **עובד בלי קליטה.** השינויים נשמרים בטלפון ונשלחים כשהרשת חוזרת.
- **וואטסאפ:** כפתור להזמנת בני משפחה, וכפתור לשליחת הרשימה עצמה מסודרת לפי מחלקות.
- **מתקינים מהדפדפן (PWA)**, כך שהיא נראית ומתנהגת כמו אפליקציה רגילה במסך הבית.

## מבנה

```
public/                 ← האתר עצמו (זה מה שעולה ל-Netlify)
  index.html            מסכים: ברוכים הבאים, שם, הרשימה
  app.js                ממשק, פעולות, וואטסאפ
  store.js              שכבת נתונים: Firebase Auth אנונימי + Firestore עם מטמון אופליין
  categories.js         מנוע הסיווג למחלקות (מילון + כללים)
  icons.js              אייקוני SVG לכל מחלקה
  styles.css            עיצוב, מצב בהיר וכהה
  firebase-config.js    פרטי הפרויקט ב-Firebase (לא סודיים)
  sw.js, manifest.webmanifest, icons/   ← התקנה כאפליקציה ועבודה בלי רשת
firestore.rules         כללי האבטחה של מסד הנתונים
firebase.json           הגדרות לפריסה דרך Firebase CLI (אופציונלי)
SETUP-he.md             מדריך הקמה מאפס, צעד אחר צעד
```

## איך הסיווג עובד

בעברית שם העצם הראשי מגיע ראשון ("לחם מחמצת", "מיץ תפוזים", "שמן זית"), ולכן **המילה המזוהה הראשונה בשם קובעת את המחלקה**. כשיש תיקו, מנצחת המילה הארוכה יותר. מילים כמו "קפוא" או "שימורים" קובעות בכל מקום בשם. המנוע מנרמל אותיות סופיות (ן→נ), גרש וגרשיים, ותחיליות ו/ה/ב/ל/מ.

קטגוריה שבוחרים ידנית גוברת על הבחירה האוטומטית, אבל רק אם בוחרים אותה אחרי שמתחילים להקליד.

## אבטחה

- כל רשימה נמצאת ב-`lists/{קוד}/items`. הקוד הוא 24 תווים אקראיים מתוך קישור ההזמנה, ואי אפשר לדפדף בין רשימות.
- רק מכשיר שנכנס, גם אנונימית, יכול לקרוא ולכתוב. כל פריט נבדק בכללים: שדות מותרים, אורכים וסוגים.
- `firebase-config.js` גלוי בכוונה. מפתחות ווב של Firebase מזהים את הפרויקט ולא מעניקים הרשאות, וההגנה מגיעה מ-`firestore.rules`.

## פריסה

- **אתר:** Netlify, פרויקט `alaluf-family-list`. מעלים את התיקייה `public` (או קובץ zip שלה) ב-Deploys.
- **Firebase:** פרויקט `family-shop-list-5a0a3`, מסד הנתונים ב-`me-west1` (תל אביב). כללים: Firestore ← Rules, או `npx firebase-tools deploy --only firestore:rules`.
- הקמה מאפס: ראו [SETUP-he.md](SETUP-he.md).
